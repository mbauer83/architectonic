# 0.11.1 — detail

A defect release. Each item names the mechanism that changed.

## Diagram ownership

`is_standalone` treated any `diagram-entities` mapping on a diagram that is not scope-bound as the
diagram's membership. It now asks the diagram type through `diagram_entities_are_authoritative`,
the predicate the renderer already used. That is true for activity, sequence, datatype, the C4 types
and GSN, and false for every ArchiMate type, matrices and the assurance types. `membership_refusal`
takes the verifier for the same reason.

## Upgrade tiers

`src/infrastructure/cli/_upgrade_tiers.py` classifies each root the upgrade is given. A tier the
deployment does not own (the workspace enterprise root, or one named with `--enterprise-root`) is
evaluated and reported, and written only with `--admin-mode`. The container entrypoint passes
`--enterprise-root` and, when `ARCH_ADMIN_MODE` is set, `--admin-mode`. A written repository is
committed ("Upgrade the persisted repository format") only when it is its own top level and its tree
was clean before the upgrade wrote; otherwise the files are left uncommitted and the reason is
printed. A backend reads an enterprise tier at the previous format unchanged.

## Rendering

- GSN's native SVG is rasterised by `rendering/svg_to_png.py` (resvg in an isolated child process,
  the mechanism icons already used) at `render_dpi()/96`, capped by the PlantUML size limit, on
  `#FFFFFF`. The canvas is read by `rendering/svg_extent.py`.
- The viewer fits a diagram by the SVG element's bounding box instead of its first group.
- Junction marks are declared in the ontology: the junction types carry `conjunctive-junction` and
  `disjunctive-junction`, and `element_appearance.mark_classes` maps them to `filled` and `hollow`.
  The declaration writer reads `ElementAppearance.mark_for`.
- `generated_header.stated_skinparams` is the one list of header skinparams; the renderer, the header
  refresh and the include injection (`completed_header`) read it.
- An activity condition gains a question mark only when it does not already end in one.

## Reads

- A matrix's context lists `from-entity-ids` and `to-entity-ids` (`axis_entity_ids`).
- `DiagramContextResponse.derived_entities` serves the same rows as `DiagramPreviewResponse`,
  produced by one function (`routers/diagrams/_derived_entities.py`). The C4 panel groups by each
  row's `item_type`; `buildC4RoleMap` and the type-table grouping are removed. Diagram-type slot
  components receive the rows as `derivedEntities`.
- `/api/diagrams/{id}/svg` and `/api/diagrams/{id}/download` answer 404 for a matrix.
- The SPA shell (`/`, `index.html`, client-route fallbacks and their 304s) carries
  `Cache-Control: no-cache`.

## Writes

- `full_entity_spellings` spells the `entity_ids` an edit is given in full through
  `canonical_ids_by_stem`; an ambiguous or unknown stem is kept as given.
- `exclusive_claim_guard.refuse_second_whole` refuses a connection whose type declares
  `exclusive_target` when another source already claims the target, reading
  `claims_its_target_exclusively` as `E340` does.
- The MCP call handler answers an `UnexpectedToolError` whose cause is a `ValueError` or a
  `MutationRejected` with the cause's message, logged at INFO. Other exceptions still read as a
  crash.

## GUI

- `ui/lib/motionPreference.ts` `motionAllowed()` is the reduced-motion predicate; the force layout's
  cooling and the cluster/radial tweens read it.
- `ROUTE_TEMPLATES.layeredExploration` is the route the router and the Viewpoints page link share.
