# 0.2.0 — complete route map

Every address 0.2.0 retires, and the canonical one that replaces it. Split out of `CHANGELOG.md`,
which a reader should be able to finish: the mapping is a lookup table, not prose, and it is
79 rows long.

Held against the source of truth rather than maintained by hand:
`src/infrastructure/rest/route_policy/_retired.py` is where a retirement is declared, and
`tests/architecture/test_changelog_route_mapping.py` fails if this file and that declaration
disagree in either direction. Do not edit a row here without editing the declaration.

A few changes are not renames and so cannot appear as a row — a route that split in two, four that
collapsed into one, a body-discriminated operation that became two addresses. Those are in the
0.2.0 section of `CHANGELOG.md`.
