# 0.11.2 — detail

A defect release about records a diagram holds: ids of the form `DIAGRAM_ID#type/local` that live in a
diagram's `diagram-entities` and have no file of their own.

## Identity

`stable_id` cut a qualified id at its last dot, which lies inside the host diagram's slug, so every held
record shared its diagram's stem and stem-matching lookups (`expand_artifact_id`, `_MemStore.canonical_id`)
could answer a record for the diagram. The stable form of a held record is now its host's stable form
with the local part kept (`DIAG@e.r#type/local`); it survives a rename of the diagram like any other id.

## Writes

`find_file_by_id` resolves standalone artifacts; a held record now has no file (`_scope_registry`, and the
bulk write's staged state). `boundary.refuse_diagram_hosted` (and `hosted_refusal`, for the bulk
preflight's per-item results) refuses an entity write addressed to a held record and names its diagram;
entity delete, edit, the enterprise admin edit, both ends of `add_connection`, promotion's selection and
the bulk delete preflight call it first.

## Index

A diagram type states which `diagram-entities` keys hold records: `held_record_keys`, by default its
declared diagram-only types; GSN, bow-tie and control structure state `nodes`. That statement and the
workspace-scoped types form one `HeldRecordScope` per type, produced once by `held_record_scopes`
(replacing two producers of the workspace half). Extraction, local-id resolution and connection endpoints
read only held keys; a type the scope does not name holds nothing. Callers pass `record_scopes`.

## Verification

`diagram_body_is_reconcile_owned` and E318's skip ask `body_is_rendered_from_diagram_entities`, the owner
the write path asks, and exclude types drawn from the assurance store (`StoreGraphProjectingDiagramType`).
Reading occurrence statements moved from the rendering layer to `application/diagram_occurrences.py`
(`occurrence_entities`, `backing_entity_ids`); the verifier's alias lookup resolves occurrence aliases
through it, after restoring the `bindings:` shorthand.
