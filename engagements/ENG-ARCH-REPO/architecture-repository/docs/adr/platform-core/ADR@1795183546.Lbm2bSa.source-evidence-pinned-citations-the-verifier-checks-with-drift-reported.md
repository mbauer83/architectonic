## Context

Model content produced by [Reverse Architecture](../../../projects/platform-core/model/common/process/PRC@1777293168.CYgU64.reverse-architecture.md) comes from somewhere: a file, a block, a line range in a source repository. Today that origin is at most a free-text property nothing checks, so it cannot be relied on and it goes stale silently.

Alternatives considered:

- **A typed reference attribute, unverified.** Small, and it gives the appearance of traceability without the substance.
- **Verify a citation when it is written and never again.** The cited source changing afterwards is exactly what a reader needs to know.
- **Pinned citations that are verified, with drift reported** (chosen).

## Decision

An entity or a connection may carry source evidence: a repository, a revision, a path and a line range. The [Model Verifier](../../../projects/platform-core/model/application/application-component/APP@1712870400.ca3vm7.model-verifier.md) checks that each citation resolves at its pinned revision. A drift report says where the cited range has changed since the pin, following the pattern derived views already use: a snapshot, provenance per item, and a refresh that detects movement.

The platform verifies the model and the citations the model holds. It does not judge the implementation: whether a changed source still conforms to the model remains a reviewer's or an agent's judgement, as [Express Divergence from the Model as Addressable Findings](../../../projects/motivation-narrative/model/motivation/requirement/REQ@1785967361.l64Hox.express-divergence-from-the-model-as-addressable-findings.md) holds. That requirement's sentence that the system never verifies the implementation is narrowed accordingly when this is built.

The reverse-architecture skill records evidence while it reads, so citations are written by the step that has the source open.

## Consequences

- The backend reads files in source clones at a path and revision that model content names. That is file access with server authority driven by authored content, and it needs its own safety analysis before it ships: reads confined to declared clones, revisions and paths validated, and nothing echoed beyond the cited range.
- A citation is a claim with an expiry; drift is reported, never repaired automatically.
- Not yet implemented.
