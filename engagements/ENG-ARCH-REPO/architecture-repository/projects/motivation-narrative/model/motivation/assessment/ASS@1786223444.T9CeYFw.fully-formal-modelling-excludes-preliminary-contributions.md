## Fully Formal Modelling Excludes Preliminary Contributions

Because every write demands a type before it will accept a name, and every connection is refused unless the ontology permits the triple, the repository can only receive work that has already been settled. Preliminary structure — the boxes and arrows that precede the decision — has nowhere to go, so it is worked out elsewhere and only its conclusion is transcribed. The rigour that makes the model trustworthy is the same property that closes it to the stage of work that produces the model's content.
