## Deviations of Built Systems from the Model Detected and Reported

Where a built system has diverged from the architecture model, the divergence is found and reported as structured deviations against the artifacts concerned, rather than surfacing later as unexplained drift — so the model and the system can be brought back into agreement deliberately, and what was learned can be fed back.
