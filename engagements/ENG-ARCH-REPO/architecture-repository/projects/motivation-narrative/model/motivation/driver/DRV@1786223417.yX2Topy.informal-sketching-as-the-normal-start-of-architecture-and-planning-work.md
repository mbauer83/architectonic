## Informal Sketching as the Normal Start of Architecture and Planning Work

Architecture, portfolio and planning work characteristically begins as informal sketching — boxes, arrows and titles on a whiteboard or in a notebook — long before the structure is settled enough to be typed against a meta-ontology. This is not a deficiency in practice but how the work proceeds: the structure is discovered by drawing it, not known in advance.
