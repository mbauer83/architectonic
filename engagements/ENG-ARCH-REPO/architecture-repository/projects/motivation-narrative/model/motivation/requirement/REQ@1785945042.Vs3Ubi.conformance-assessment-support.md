## Conformance Assessment Support

The system shall expose the architecture model for assessment against a proposed change before that change is made — through the same verifier, query and derivation surfaces that govern authoring, so what a reviewer or agent compares against is the model as the system itself reads it. Each divergence is expressed as a finding against an addressable artifact rather than as prose, which is what makes it actionable. Performing the review is the reviewer's work; making it possible without first reconstructing the model is the system's.
