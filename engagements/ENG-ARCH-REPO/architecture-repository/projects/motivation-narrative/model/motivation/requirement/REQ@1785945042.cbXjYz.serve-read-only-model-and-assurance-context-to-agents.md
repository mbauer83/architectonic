## Serve Read-Only Model and Assurance Context to Agents

The system shall serve architecture and assurance context to agents and LLMs over a read-only surface — the model content a change touches, what else it reaches, and implementation and assurance-method guidance. Nothing an agent derives from that context becomes model content without passing the same authoring and verification surfaces as any other write. The context served is authoritative; what is built on it is not.
