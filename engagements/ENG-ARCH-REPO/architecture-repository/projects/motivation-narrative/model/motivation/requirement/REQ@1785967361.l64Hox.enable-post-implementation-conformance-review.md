## Enable Post-Implementation Conformance Review

The system shall expose the architecture model, its constraints and its derived relationships so a reviewer or agent can assess a system as built against it and express each divergence as a finding against an addressable artifact. Performing the review is the reviewer's work; the system's is to make the model, and what it permits, readable enough to review against.
