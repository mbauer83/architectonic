## Deployment-Level Guidance Import

The system supports importing published, license-encumbered authoring guidance from a configurable external source into one local, out-of-repo cache per deployment — never split per engagement/enterprise repository tier, and never committed to any repository's git history. The imported guidance is layered: alias-independent workspace-level topics, per-module meta-ontology-level context, and per-domain, per-entity/connection-type, and per-specialization guidance — composed broadest-first when authoring guidance is served.
