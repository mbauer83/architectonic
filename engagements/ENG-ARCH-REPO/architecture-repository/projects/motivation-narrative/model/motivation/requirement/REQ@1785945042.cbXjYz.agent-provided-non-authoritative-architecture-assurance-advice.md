## Agent-Provided Non-Authoritative Architecture & Assurance Advice

The system shall serve architecture and assurance context to agents and LLMs so they can advise on a proposed change — retrieving the model content a change touches, discovering what else it reaches, and delivering implementation and assurance-method guidance. That advice is non-authoritative: it never gates the change, and nothing an agent derives from the context becomes model content without passing the same authoring and verification surfaces as any other write. The context served is authoritative; the advice built on it is not.
