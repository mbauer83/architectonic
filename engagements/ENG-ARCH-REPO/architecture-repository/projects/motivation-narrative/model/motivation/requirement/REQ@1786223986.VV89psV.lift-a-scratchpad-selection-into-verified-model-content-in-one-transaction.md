## Lift a Scratchpad Selection Into Verified Model Content in One Transaction

The platform must turn a selected set of notes and the links among them into entities and connections in a single transaction through the ordinary verified write path, reporting beforehand what would be created, what is skipped, and what is refused. A partially lifted selection must not be reachable.
