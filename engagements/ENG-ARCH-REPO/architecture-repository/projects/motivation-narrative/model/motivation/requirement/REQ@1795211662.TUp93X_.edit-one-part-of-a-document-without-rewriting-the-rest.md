## Edit One Part of a Document Without Rewriting the Rest

The system shall let an author or an agent change one section of a document, replace a stated text in it, or add, change and remove rows of a table its document type declares, leaving the rest of the document unchanged. A change or removal of a table row states the row as it was read, and is refused, naming the row and both values, when the row has changed since; edits to different rows by different writers both succeed. Every such edit is verified as a whole-document write is.
