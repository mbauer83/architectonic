## Declare a Meta-Ontology's Classification Levels in the Ontology Module

A meta-ontology must state what its classification levels are and how each behaves — which level relationships are keyed on, which levels merely narrow, which carry attributes, and which are required before content may be lifted. Consumers must read that declaration rather than assume ArchiMate's domain-type-specialization shape, so a module declaring a different depth is followed without changing any consumer. The levels describe the segments `hierarchy` already declares per entity type; they do not restate them.
