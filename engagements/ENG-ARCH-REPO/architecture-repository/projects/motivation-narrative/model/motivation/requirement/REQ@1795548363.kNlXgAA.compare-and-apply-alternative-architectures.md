## Compare and Apply Alternative Architectures

The system shall hold alternative changes to the architecture beside the model, each named and argued, show for every proposed edit whether it still applies to the model as it is now, and write a chosen alternative into the model as one verified change or not at all. Alternatives that were not chosen remain readable.
