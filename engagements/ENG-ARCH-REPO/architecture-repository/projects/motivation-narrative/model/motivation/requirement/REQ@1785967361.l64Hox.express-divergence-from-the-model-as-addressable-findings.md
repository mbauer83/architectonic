## Express Divergence from the Model as Addressable Findings

The system shall expose the architecture model, its constraints and its derived relationships so a reviewer or agent can assess a system as built against it and express each divergence as a finding on the model artifact it departs from. Comparing a built system to the model is judgement an agent or reviewer performs, holding both; the system verifies the model, never the implementation. The platform's obligation is to make the model and what it permits readable enough to review against, and to accept the resulting findings as model content.
