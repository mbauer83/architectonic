## Accept Implementation Refinements Through the Authoring Path

The system shall accept what was decided or learned while implementing a change through the same authoring surfaces, verification and history as any other write — refining the affected content and recording the decisions behind it. Feedback from implementation therefore enters the model as reviewable, verified content rather than as commentary held outside it. Deciding what to feed back is the implementer's work; giving it a way in that the model can hold is the system's.
