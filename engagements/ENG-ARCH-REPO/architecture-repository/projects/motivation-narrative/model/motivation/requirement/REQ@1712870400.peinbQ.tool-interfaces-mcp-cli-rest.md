## Tool Interfaces: MCP, CLI, REST

The system shall expose its capabilities through multiple tool interfaces: MCP for AI agent integration, CLI for command-line automation and scripting, and REST for web-based integration and the GUI. All interfaces share the same underlying service layer, so behaviour and enforcement are the same regardless of access method.

The two principal surfaces — MCP, and REST together with the GUI it backs — must each be able to drive the whole system: any capability the platform offers is reachable from both, against the same model and the same verification. Their audiences differ, but their coverage does not, because a capability offered on only one of them makes either the human or the agent a second-class participant in work the platform exists to have them share. The CLI is deliberately narrower, serving power users and CI/CD pipelines rather than aiming at the same completeness.
