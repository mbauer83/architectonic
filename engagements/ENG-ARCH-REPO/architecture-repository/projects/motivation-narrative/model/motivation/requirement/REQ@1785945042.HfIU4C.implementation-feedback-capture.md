## Implementation Feedback Capture

The system shall let what was decided or learned while implementing a change be recorded back into the architecture model — refining the affected content and capturing the implementation decisions behind it — through the same authoring surfaces that govern any other write. Feedback from implementation therefore enters the model as reviewable, verified content rather than as commentary held outside it.
