## Pre-Implementation Conformance Check

The system shall let a proposed implementation change be assessed against the current architecture model before the change is made, and report where implementation and model diverge. The assessment reads the model through the same verifier, query and derivation surfaces that govern authoring, so a deviation it reports is one the model itself recognises, and it names the artifacts involved rather than only reporting that a difference exists.
