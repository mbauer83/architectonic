## Hold Alternatives for a Scratchpad Note and Lift Only the Active One

The platform must let a note carry competing alternatives that vary its type and content, keep exactly one of them active, and lift only the active one — since two lifted alternatives would enter the model as contradictory fact. Switching the active alternative must re-run link verification, so the canvas can show which alternative fits the ontology in context.
