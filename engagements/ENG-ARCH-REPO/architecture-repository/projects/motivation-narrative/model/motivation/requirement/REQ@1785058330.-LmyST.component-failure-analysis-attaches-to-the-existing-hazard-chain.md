## Component Failure Analysis Attaches to the Existing Hazard Chain

A per-component failure analysis must express the consequence of a failure as a link to a hazard the system analysis already states, and must not introduce a second vocabulary of effects, consequences or severities alongside it.

Without this, the second method costs what the first one did: its own losses, its own hazards, its own severity scale, and two accounts of the same consequence that drift apart and then have to be reconciled by hand. With it, the analysis that a component's failure matters is a link, its severity is read from the losses that link reaches, and adding the method to an existing analysis costs a row per component rather than a restatement of the system.

The reverse containment holds too: a finding where nothing failed — a coordination flaw, an unsafe but correct action — is not a failure mode, and recording it as one would put a second control analysis inside the failure worksheet.
