## Refine a Scratchpad Note Along the Meta-Ontology's Classification Hierarchy

The platform must let a note progress toward becoming a model element, a document, or neither — and where it becomes an element, must narrow it by following the hierarchy the active meta-ontology declares rather than a fixed set of steps. For ArchiMate 4 that is domain, then entity type, then specialization; a domain is a genuine first narrowing because most areas permit several. Each level offers what the level above allows, the area's permitted set first and the rest marked as outside it, and every step is reversible while the note holds no model reference.
