## Renderer Input-Safety Test Suite

Pytest modules that exercise the diagram pipeline's boundary defences against user-supplied PlantUML: `tests/rendering/test_puml_safety_startuml_name.py` and `tests/rendering/test_puml_safety_user_input.py`. Between them they cover control-character collapsing in diagram names before those names are embedded in frontmatter or a PlantUML title line, and rejection of file and network preprocessor directives in a submitted body before it is prepared, rendered or stored. Run by the backend quality gate on every change.
