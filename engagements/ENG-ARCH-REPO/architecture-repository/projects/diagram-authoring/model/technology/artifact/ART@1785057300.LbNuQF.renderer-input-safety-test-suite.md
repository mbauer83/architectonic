## Renderer Input-Safety Test Suite

Pytest modules that exercise the diagram pipeline's defences against PlantUML bodies that reference files, URLs or environment values: `tests/rendering/test_puml_safety_startuml_name.py`, `tests/rendering/test_puml_safety_user_input.py` and `tests/rendering/test_a_puml_body_cannot_reference_files_or_urls.py`. Between them they cover control-character collapsing in diagram names before those names are embedded in frontmatter or a PlantUML title line; the body policy that allows only the bundled standard library, the managed fragments and embedded images, refusing every other include, import, environment or filesystem builtin and image reference on the create and edit write paths, the on-demand and on-disk renders, and the verifier's syntax check; and PlantUML's sandbox profile, tested with the body policy bypassed, together with a fitness function that nothing starts PlantUML except the one command builder. Run by the backend quality gate on every change.
