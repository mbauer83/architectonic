## Diagram Layout

The optional geometry a diagram states about itself: where each instance sits and how large it is, how boxes are sized, where each drawn relation attaches and bends, where its label sits, and how things stack. Held in the diagram's frontmatter and keyed by the identities the diagram already uses; removing it returns the diagram to PlantUML's arrangement with nothing else changed.
