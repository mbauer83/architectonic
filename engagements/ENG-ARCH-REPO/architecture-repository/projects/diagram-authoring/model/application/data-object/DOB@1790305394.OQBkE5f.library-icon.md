## Library Icon

A picture a repository's diagrams may show on their elements, stored as text so every git workflow carries it: its name, attribution, the types and specializations it may be shown on, a default style, tags and a status, then the normalised PNG and, for an SVG upload, the cleaned SVG. Its picture never changes under its id; a new version is a new icon.
