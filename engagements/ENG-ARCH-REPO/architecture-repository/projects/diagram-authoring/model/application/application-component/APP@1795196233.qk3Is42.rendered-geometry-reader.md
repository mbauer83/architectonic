## Rendered Geometry Reader

Reads the picture the PlantUML Renderer drew of a diagram into its geometry: each element's shape, the boxes with their nesting, each relation's path, end marks and label, and the measured width of each word, addressed by the aliases the picture carries. It reads a picture whole or answers that it is not readable and names what it met; a structure it does not recognise is never read in part.
