## Icon Library

The component that holds the pictures diagrams show on their elements. It checks an upload — an SVG is rebuilt from an allow-list of elements and attributes and rasterised in an isolated process, a raster decoded within size limits — and stores it as one normalised PNG, refusing a picture the library already holds. It answers which icon each instance of a diagram shows, by the precedence the renderer draws, re-points every diagram from one icon to another, moves an icon a diagram holds for itself into the library, and refuses to delete or narrow an icon while an element shows it.
