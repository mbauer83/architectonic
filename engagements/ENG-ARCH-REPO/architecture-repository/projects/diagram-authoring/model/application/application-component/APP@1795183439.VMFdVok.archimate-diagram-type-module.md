## ArchiMate Diagram Type Module

Pluggable diagram-type family for ArchiMate views: one view type per domain — motivation, strategy, business, application, technology, implementation — and a layered view across them, each declared by configuration over the ArchiMate ontology. Its diagrams are model-owned: every element drawn is a model entity, and the body is generated from the entities and connections the diagram names.
