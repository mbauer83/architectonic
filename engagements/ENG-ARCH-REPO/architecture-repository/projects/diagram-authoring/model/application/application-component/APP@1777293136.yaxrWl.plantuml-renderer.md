## PlantUML Renderer

Converts textual PlantUML diagram representations to raster and vector images (PNG/SVG) by invoking an external PlantUML JAR, incorporating the generated ArchiMate macro library for correct stereotype rendering. The JAR is always started under PlantUML's sandbox security profile, through one command builder, so a body cannot make it read local files or fetch URLs; the managed macro fragments are inlined into a body before it is handed over. A diagram type that draws its own SVG, as GSN does, does not pass through it; the PNG of such a diagram is rasterised from that SVG.
