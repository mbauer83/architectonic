## Detect Accepted Changes

Decide, for each submitted change, whether the enterprise artifact now says what it asked, and close the ones that do.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

Decided by comparing the fields the change names against what the artifact currently holds. Replaying the change and comparing the result would compare against a re-rendering — which normalises quoting, ordering and spacing — so an accepted change and an unaccepted one both come back different and the comparison answers nothing.

Every named field must be readable and equal. A field with no current reading counts as not accepted, and so does an artifact that cannot be read at all: a change left open can still be submitted, while one closed in error is a change that silently never happens.

Only a submitted change is closed this way. A draft has been sent to nobody, so an artifact that happens to match it is a coincidence rather than an acceptance, and closing it would discard work its author never put forward.
