## Record a Proposed Change

Turn an edit an engagement makes to an enterprise-owned artifact into a recorded change against it, where a write would reach content the engagement does not own and a refusal would leave the author nowhere to go. The record names the fields the edit touches and what the artifact was when the edit was made.
