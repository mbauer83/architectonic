## Serialize Assurance Store Writes

Admits every mutation of the confidential assurance store through one single-writer FIFO queue, so concurrent callers cannot interleave writes.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

The behaviour the Assurance Write Queue performs. Every assurance mutation reaches the store through it — the MCP write tools, the assurance REST routes, and signal ingestion alike — which is what makes the single-writer guarantee a property of the store rather than of any one caller.
