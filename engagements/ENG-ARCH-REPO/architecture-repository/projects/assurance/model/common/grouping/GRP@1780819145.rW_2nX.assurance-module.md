## Assurance Module

Concern boundary (module_class: assurance) grouping the assurance verifier, supply-chain connector, archive, confidential store, and their accessed data-objects; in-process within Architecture Backend, not a separate deployment boundary.

The module's own ontology declares the assurance vocabulary, including the failure-mode type and the relations that keep component failure analysis attached to the system hazard chain rather than beside it: a failure mode leads to a hazard the analysis already states, a control detects a failure mode, and a loss scenario explains one. It declares no derivation roles, so none of these relations composes — "A leads to B, B leads to C" is not a claim any analyst made, and a causal vocabulary must not become composable in a query.
