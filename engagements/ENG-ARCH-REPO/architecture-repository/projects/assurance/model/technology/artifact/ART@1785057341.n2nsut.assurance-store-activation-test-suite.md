## Assurance Store Activation Test Suite

Pytest modules covering how access to the encrypted store is granted, withheld and withdrawn: `tests/assurance/test_activation_policy.py`, `tests/assurance/test_store_factory.py`, `tests/assurance/test_store_factory_locking.py` and `tests/assurance/test_assurance_auto_unlock_recovery.py`. They assert that the shipped default requires a per-process authorization even when the activation gate is set, that the unattended policy opens from the gate but never without it, that revoking closes a store already open in a running process rather than only at the next start, and that an unrecognised policy or an unreachable credential backend leaves the store locked. Run by the backend quality gate on every change.
