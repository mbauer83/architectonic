## Assurance Archive Tamper-Evidence Test Suite

Pytest modules covering the append-only audit archive: `tests/assurance/test_assurance_archive.py` and `tests/assurance/test_encrypted_git_archive.py`. They assert that every mutating assurance operation appends an entry, that the hash chain detects an altered or removed entry, and that the encrypted-git archive backend preserves the same properties. Run by the backend quality gate on every change.
