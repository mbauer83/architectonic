## Assurance Classification-Enforcement Test Suite

Pytest modules covering the clearance check applied to everything the store returns: `tests/assurance/test_max_classification.py`, `tests/application/test_assurance_exposure.py`, `tests/assurance/test_assurance_node_sort_exposure.py` and `tests/domain/test_tlp_scale_agreement.py`. They assert that an entry above the requestor's clearance is withheld rather than redacted, that withholding is counted so a truncated result is visibly truncated, that ordering a result set cannot leak the existence of a withheld entry, and that every surface agrees on the ordering of the classification scale. Run by the backend quality gate on every change.
