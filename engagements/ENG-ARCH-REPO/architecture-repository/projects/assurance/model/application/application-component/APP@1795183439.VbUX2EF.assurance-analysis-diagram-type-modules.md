## Assurance Analysis Diagram Type Modules

The diagram types of the assurance module family: bow-tie, STPA control structure, the unsafe-control-action matrix and the failure-mode matrix. They are registered only where the confidential store is configured. The two matrices are drawn by the GUI as grids and have no PlantUML body.
