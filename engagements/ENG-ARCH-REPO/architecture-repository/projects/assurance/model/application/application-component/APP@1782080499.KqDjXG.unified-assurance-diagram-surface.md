## Unified Assurance Diagram Surface

Frontend viewer surface that renders assurance diagram types (bowtie, control-structure, UCA-matrix, failure-mode matrix) directly from the confidential assurance store, with selectable nodes and edges that open assurance detail panels. Replaces the generic diagram viewer for these types, which are no longer discoverable or renderable outside the assurance surface. Membership in this surface is derived from a diagram type's declared capability to project its content from a store graph rather than from a list of type names — which is why GSN is dual-homed: it is repository-backed like any other diagram, so it renders in the generic architecture viewer, and reaches the assurance bridge only when confidential-store-backed.

The failure-mode matrix is the surface's one grid: elements down, failure guidewords across, and a cell that distinguishes examined-and-recorded from examined-and-dismissed from never-looked-at, so an unstarted analysis cannot be mistaken for a finished one. Its rows are a nomination — the elements a control structure already names, plus the ones the architecture graph shows to be load-bearing — never every element in the model.
