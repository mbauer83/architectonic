## Assurance Verifier

Runs hard structural validity checks, the safety-disposition safeguard (safety never subordinate to risk), and opt-in method-completion profiles on assurance content; parallel to the existing Model Verifier.

Its failure-mode rules are mostly about coverage rather than validity, because the characteristic failure of a per-component worksheet is not an invalid row but an absent one. They report an element the control structure already names that nobody has examined, one the architecture graph shows to be load-bearing that no analysis has reached, and a failure mode with no hazard or no detecting control — the two absences that leave its priority underivable. Two rules are hard: an asserted severity may lower what the hazard chain reaches but never exceed it, and a priority band may never be used to close, weaken or defer a safety or security constraint.
