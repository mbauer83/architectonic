### archimate-aggregation → BOB@1786225252.4SAEdhC.scratchpad-note

An area gathers the notes lying within it. Aggregation rather than composition: membership is spatial and changes when a note is dragged, and a note outside every area is legitimately unfiled — so the area does not govern the note's lifecycle, the scratchpad does.
