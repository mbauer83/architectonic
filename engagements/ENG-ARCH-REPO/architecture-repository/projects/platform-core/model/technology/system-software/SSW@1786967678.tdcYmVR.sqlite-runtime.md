## SQLite Runtime

The embedded SQLite engine the read model runs on, in the backend's own process.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

Embedded rather than served: there is no database process to reach over a network, which is why the read model is a single file on a volume and why concurrency is copy-on-write rather than client-server.
