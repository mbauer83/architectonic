## Platform HTTP Endpoint

Port 8000 inside the container: the GUI, the REST surface and MCP are all served from it.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

One endpoint for three surfaces, which is why there is one container, one healthcheck and one restart unit. The published host port is the operator's to choose; inside the container it is always 8000, which is why the healthcheck probes that rather than the published one.
