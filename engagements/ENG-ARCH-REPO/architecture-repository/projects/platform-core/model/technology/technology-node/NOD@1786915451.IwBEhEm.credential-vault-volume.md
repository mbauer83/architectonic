## Credential Vault Volume

Mounted storage holding the runtime user's home, and with it the assurance credential vault.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

Mounted at /home/arch. The vault lives under $HOME rather than beside the store so that losing the store does not also lose the key, and so the runtime user has a real, persistable home.
