## App Container

The single container the compose file starts from the Architectonic image: one process serving the GUI, the REST surface and MCP on port 8000.

## Notes

One container rather than one per interface, and that is the fact this node exists to record. The backend serves the built SPA itself, so there is no separately deployed front end: one port, one healthcheck, one restart unit.

It runs as a non-root user (uid 10001) with a real home, because the assurance credential vault lives under `$HOME`. Writable state is mounted rather than baked in — the cloned repositories, the backend's state directory, the encrypted assurance store and the vault each arrive on their own volume, so the image stays reproducible and the state survives replacing it.
