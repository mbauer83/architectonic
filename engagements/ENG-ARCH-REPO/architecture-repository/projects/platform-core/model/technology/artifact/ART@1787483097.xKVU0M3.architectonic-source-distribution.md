## Architectonic Source Distribution

The installed project — backend package and built web assets — from which a workstation runs the platform directly, without a container image.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

The deployable the developer-workstation topology uses, as the container image is the deployable the team-serving topology uses. One component, two artifacts realizing it, because the two topologies obtain it differently: a workstation runs the backend under its own Python runtime and serves the built assets from the same tree, while a team-serving host runs both from an image.

Modelled because the model held only the image, so nothing on a workstation realized the backend or the authoring tool, and a deployment view of that topology drew the two stores and neither of the things a developer actually runs.
