## Assurance Credential Vault

The file holding the assurance store's encryption key where no operating-system keychain exists, as in a container: one Fernet-encrypted JSON document whose key is derived from the master password with PBKDF2. Lives at $HOME/.config/arch-assurance/vault.enc.

## Properties

| Attribute | Value |
|---|---|
| Format | Fernet-encrypted JSON |
| Git Tracked | No |
| Key derivation | PBKDF2-HMAC-SHA256, 480,000 iterations |
