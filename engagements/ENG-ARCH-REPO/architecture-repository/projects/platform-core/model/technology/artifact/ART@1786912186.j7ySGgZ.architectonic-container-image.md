## Architectonic Container Image

The deployable unit of the platform: a multi-stage image carrying the built SPA, the resolved Python environment and the diagram runtime, run as one long-lived process.

## Notes

Built in three stages — the Vue SPA, the Python environment resolved with uv, and a slim runtime that keeps the `/app` source layout because the application discovers the PlantUML jar, its settings and the built SPA by walking it.

It carries the diagram toolchain it shells out to (a headless JRE and Graphviz), which is why the image is larger than the Python application alone would need.

One container serves the GUI, the REST surface and MCP on port 8000. Writable state lives in mounted volumes rather than the image: the cloned repositories, the encrypted assurance store, the backend's own state directory and the credential vault.
