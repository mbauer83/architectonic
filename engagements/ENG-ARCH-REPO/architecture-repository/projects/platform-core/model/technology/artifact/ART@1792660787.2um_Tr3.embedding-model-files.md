## Embedding Model Files

The three files the embedding model is loaded from — configuration, safetensors weights and tokenizer, about 31 MB together — each checked against a pinned SHA-256 digest. Acquired by get-embedding-model into models/ beside the installation, or a directory ARCH_EMBEDDING_MODEL_DIR names; never committed and never part of the container image.

## Properties

| Attribute | Value |
|---|---|
| Format | config.json, model.safetensors, tokenizer.json |
| Git Tracked | No |
| Lifecycle | Installed asset; a missing or altered file disables vector retrieval |
| Size | About 31 MB |
