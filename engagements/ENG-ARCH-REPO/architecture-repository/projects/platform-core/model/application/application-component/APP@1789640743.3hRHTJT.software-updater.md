## Software Updater

The component behind arch-update. It reads the publisher's release record, verifies the tag signature against the signers the installation trusts, the release commit against the fetched tag and each asset against the published digests, and observes the installation: its checkout, dependency selection, backend, assurance store and deployment kind. It plans the update as a decision table whose every refusal names a remedy, rehearses the next version's data upgrade in a throwaway worktree, and applies the plan as a journaled sequence of phases in which the installed version runs up to the environment sync and then re-executes itself as the new version for the rest. A failure in any phase reverses what the journal says was reached. One implementation of the phases exists per deployment kind: a local checkout, and a compose host that builds an image and migrates inside it.
