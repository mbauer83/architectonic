## Workspace Administration Toolkit

Command-line tooling that acts on the repository, the workspace and the assurance store directly, without passing model or analysis content through the Architecture Backend: workspace initialization and engagement switching (arch-init, arch-switch-engagement), repository format upgrade (arch-repair), guidance import (arch-import-guidance), model exchange (arch-exchange), and assurance store administration (arch-assurance — init, unlock/lock, key rotation and export, backup, restore, integrity verification, storage-backend selection). What these have in common is that they operate on the repository and the store as artifacts — their format, their configuration, their keys, their contents as a corpus — rather than on the model through the application's own affordances. Several of them must work when no backend can run: arch-init creates the workspace the backend requires, and arch-repair rewrites the format the backend assumes. Content is not reachable here: reading and authoring architecture and assurance content go through the backend, over REST for the GUI and over MCP for agents. arch-assurance unlock authorizes the running backend rather than bypassing it. The absence of a serving relation from the Architecture Backend is therefore a fact about this component, not an omission.
