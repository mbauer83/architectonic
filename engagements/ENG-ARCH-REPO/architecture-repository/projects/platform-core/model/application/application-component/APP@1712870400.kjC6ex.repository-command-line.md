## Repository Command Line

HTTP client of the Architecture Backend for repository operations from a shell (arch-write-cli): entity, connection, diagram and document authoring, verification, querying and promotion, for power users, scripting and CI/CD pipeline integration. Every affordance reachable here is the backend's, requested over the same HTTP surface the GUI and the MCP bridges use, so the same verified write pipeline governs all of them. Repository- and workspace-level administration that does not pass through the backend belongs to the Repository Administration Toolkit.
