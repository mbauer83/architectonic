## Scratchpad Canvas

The authoring surface: notes rendered as HTML in a transformed layer with links and handles drawn as SVG beneath the same transform, so that titles are edited natively and every interaction remains reachable by the browser suite. Holds the aggregate in memory behind a command stack and saves it debounced, so the endpoint sees a save rather than a drag.
