## Query and Corpus Embedder

The model that turns a query and each piece of the corpus into vectors that can be compared, held and run inside the deployment.

## Properties

| Attribute | Value |
|---|---|
| Approach | Self-supervised |
| Architecture Family | Static token-embedding lookup with pooling, distilled from a sentence transformer |
| Ethical Considerations | ["Runs entirely within the deployment, so no query or artifact reaches a third party","The confidential assurance store is excluded from what it embeds, because an embedding is a derivative of the text that produced it"] |
| Inputs | A query, or one chunk of an artifact's text |
| Licenses | ["Permissive open-source, recorded with the weights rather than in the dependency lock"] |
| Model Architecture | Token-to-vector table plus mean pooling; no attention and no forward pass at query time |
| Outputs | A unit-normalised dense vector |
| Performance Metrics | ["0.04 ms to embed one query, single-threaded","0.2 s to embed the whole corpus","Retrieval quality is measured by the labelled query suite, not asserted here"] |
| Supplier | Third-party open-weights publisher; the exact model and revision are pinned by the recorded digest |
| Task | Sentence and document embedding for retrieval |
| Technical Limitations | ["Lower ceiling than a transformer where a query shares no vocabulary with its answer, which is the only case with measurable headroom","Sized for a corpus of this order; a substantially larger one revisits the choice"] |
| Telemetry |  |

## Notes

A distilled static model rather than a transformer: it looks each token up and pools, so no query is encoded by a forward pass and none leaves the deployment. Chosen on measurement — the transformer alternative costs an order of magnitude more installed weight and two orders of magnitude more time per query for a difference in retrieval quality too small to distinguish from noise on the labelled suite.

Its weights are an installed asset with their own digest and licence, not a package the dependency lock records. A missing or corrupt file disables vector retrieval and says so; keyword search is unaffected, because keyword search is what the product promises without this.
