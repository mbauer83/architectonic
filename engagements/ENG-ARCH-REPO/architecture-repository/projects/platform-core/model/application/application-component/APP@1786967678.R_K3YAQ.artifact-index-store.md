## Artifact Index Store

The SQLite read model over a repository: what queries, searches and verification are answered from, rebuilt from the files rather than authored.

## Properties

| Attribute | Value |
|---|---|
| Backup and Recovery | Not backed up. Recovery is a reindex from the Artifact File Store, which is the only thing that has to survive. |
| Consistency Model | Copy-on-write |
| Retention | None: the index is rebuilt from the files whenever it is missing or stale, and nothing in it is authored. |
| Source of Truth | Derived |

## Notes

Derived state, not source of truth — the Model File Store is. It exists so a read never walks the file tree, and it is the store the indexer writes and the query engine reads, which is the coupling between those two components.
