## Embedding Model

The static embedding model search encodes queries and the corpus with: a token-to-vector table, its tokenizer and its configuration, pinned to one upstream revision and held within the deployment. Nothing it encodes leaves the process. Without it, vector retrieval is off and keyword search answers alone.
