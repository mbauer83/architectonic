## Update Journal

The record an update in flight keeps between its phases and across the boundary where the new version takes over from the installed one: the prior state to return to, the release being installed, the dependency selection, the phase last completed and the phase begun, the data upgrade's safety point once taken, and the command the new version is resumed with. Written before and after every phase, it is what a resume continues from and what a rollback reverses, and it retires into a history with the outcome it reached. A journal one version wrote and another cannot read fails by name rather than by surprise.
