## Release Manifest

What a published release states about itself, as the updater reads it: the version and its tag, the commit the tag names, when it was published, whether it is a pre-release, and its assets with their stated digests. The published checksum file is part of it, so an asset is verified against two independent statements of its digest. The manifest is the reference every verification is made against, never the thing verified: what it says is trusted only after the tag's signature has been checked against the signers this installation carries.
