## Corpus Embedding Index

The vectors for every searchable piece of the engagement and enterprise repositories, against which a query vector is matched.

## Notes

Built when the process starts and held in memory. Building the whole of it costs a fraction of a second, which is why it is not a file: there is no stored copy to go stale, no identity to key it by, and no superseded copy to collect.

The confidential assurance store is not in it. An embedding is a derived representation of the text that produced it, so including that content would place a derivative of it under the engagement repository's rules, where a similarity score could reveal that something exists. Assurance content is searched by its own surface, under its own ceiling.
