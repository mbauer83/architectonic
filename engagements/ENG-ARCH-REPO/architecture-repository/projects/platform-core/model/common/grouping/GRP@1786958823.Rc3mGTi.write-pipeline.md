## Write Pipeline

Everything a change passes through between arriving at a surface and being published: admission, serialization, staging, verification and announcement.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

Gathers the components that realize ADR 'One Unified Backend Authority' — one queue, one registry, one staged transaction, one verifier, whichever surface the write arrived on. A component may belong to more than one concern, so membership is aggregation rather than composition.
