## Set Up a Workspace

Everything an adopter runs before any modelling can begin: bind a workspace to its engagement and enterprise git repositories, or bring an existing pair up to the current on-disk format, then load the authoring guidance the deployment will model against. Ends where use begins — the workspace is ready, and modelling takes over. Operating the workspace once it runs is separate behaviour: writes are governed by Coordinate Reads and Writes for Consistency, which this process neither contains nor triggers.
