## Upgrade Repository Format

Bring one git repository's on-disk format up to the version the current release reads, rewriting artifacts in place and reporting what changed. Singular deliberately: a workspace binds two repositories and each is upgraded on its own. An entry point rather than maintenance — an adopter arriving with repositories authored against an earlier release starts here instead of with initialization, and the workspace is ready either way.
