## Execute Staged Write Transaction

Transactional process every architecture write passes through, whatever its size. A write is classified by blast radius: a single-artifact change commits by atomic file replace, while a change touching several files commits from an M4 manifest under a staged root. Both paths apply batch deltas, resolve reference blockers through maintained reverse indexes, verify impacted state through a live-index-plus-delta overlay, and publish atomically — so a partially applied write is not a state the repository can reach.
