## Full-Text Search

Ranks artifacts by how well the query's own terms match their names, summaries, keywords and content, and returns ranked candidates.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

The branch that answers a query using the words the artifact itself uses. Measured on this repository, it answers a query repeating an artifact's name or summary nearly always, and a query phrased differently for the same thing nearly never.

It matches on terms whichever way it has to. The indexed path is the fast one and carries the ranking; where a kind of artifact yields nothing there, the same terms are scored directly against that kind's records rather than the branch reporting nothing. Both are the same behaviour and the caller cannot tell them apart.

It produces candidates and nothing else. What a reader finally sees is decided by combining it with the branch that answers by meaning and then applying the ordering policy.
