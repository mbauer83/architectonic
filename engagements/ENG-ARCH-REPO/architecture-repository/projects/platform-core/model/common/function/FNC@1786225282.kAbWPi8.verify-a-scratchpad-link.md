## Verify a Scratchpad Link

Decide whether a link is permitted between the types its endpoints now carry: refusing what the ontology forbids and naming the permitted alternatives including the reverse direction, warning where a specialization or an area narrows rather than forbids, and treating an element-to-document link as a reference rather than a connection.
