## Vector Similarity Search

Ranks artifacts by how close their meaning is to the query, by comparing the query's vector against the corpus vectors, and returns ranked candidates.

## Properties

| Attribute | Value |
|---|---|
| (none) | (none) |

## Notes

The branch that answers a query phrased in words the artifact does not contain. Measured on this repository, the branches matching on terms answer a query repeating an artifact's own name or summary nearly always and one phrased differently for the same thing nearly never; this is the branch for the second case.

It produces candidates and nothing else. What a reader finally sees is decided by combining it with the other branches and then applying the ordering policy — this branch has no opinion about either.
