## Narrow a Scratchpad Element to the Next Classification Level

Move an element one step down the classification hierarchy the active meta-ontology declares, offering only what the level above and the area's permitted set allow. The steps are read from the meta-ontology rather than fixed: for ArchiMate 4 they are domain, then entity type, then specialization — a first narrowing to a domain being necessary because most areas permit several. A meta-ontology declaring a different depth or different level names must be followed without change here, which is why this is one repeating narrowing rather than a step per ArchiMate level. Reversible at any level while the element holds no model reference.
